# Tienda Blushy Makeup & Beauty

Página de la tienda en línea de Blushy (Florencia, Caquetá).

- `index.html`: la página.
- `productos.json`: productos, precios y unidades disponibles. Se actualiza desde la caja de Blushy.
- `ref.json`: precios anteriores que se muestran tachados.
- `img/`: fotos de los productos, logo e íconos.
